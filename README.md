# Ferretería El Bachué

Aplicativo web de inventario y ventas para una ferretería. Proyecto final de Bases de Datos II (Ruta A, relacional).

Integrantes: Johan González y Michel Yepez.

Stack: PostgreSQL 17, FastAPI, React + Vite, Docker Compose.

## Arranque rápido

```bash
cd 03_aplicacion
cp .env.example .env   # y poner valores reales
docker compose up --build
```

- Web: http://localhost:5173
- API: http://localhost:8000/docs
- pgAdmin: http://localhost:5050
